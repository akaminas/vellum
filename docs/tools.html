Pipeline

build_palettes.py runs a seeded search for tone lightness that maximises the smallest neighbour distance at 3:1 contrast. make_vellum_json.py derives tints, deeps, ramps, diverging scale, gradients and dark twin, and writes vellum.json. make_assets.py writes the five tool files.

The pipeline reproduces the published files byte for byte.

cd generators
python build_palettes.py palettes.json      # the seeded search (about 3 minutes)
python make_vellum_json.py ../style/vellum.json
python make_assets.py ../style/vellum.json ../style
git diff --stat ../style                    # nothing: the files are reproduced exactly

matplotlib

use resets the rcParams: fonts (Corbel, then Lato, Segoe UI, DejaVu Sans), surface, spines, grid, ticks, colour cycle, line width, and save options (300 dpi, Type 42 fonts). The helpers implement the anatomy.

# a paper figure: no title block, the claim goes in the caption

R and ggplot2

Source the file, add the theme and scales, put the claim in labs(title) and the unit in labs(subtitle). The theme drops the y title, legend and vertical grid.

  1. Room for end labels: expansion(mult = c(0, 0.32)) on x.
  2. Highlight: values = c(rest = vellum$rule, focus = vellum$tone[2]).
  3. Error bars: geom_errorbar(width = 0, colour = vellum$secondary, linewidth = vellum$thin).
  4. Heat map: geom_tile(colour = vellum$surface, linewidth = 0.4) with scale_fill_vellum_grad("lagoon").
  5. 3D: ggplot2 has none; use base persp for the surface.

LaTeX: pgfplots, TikZ, beamer

Load after TikZ and pgfplots. Tones vteal … vmoss, tints vtealTint, deeps vtealDeep, neutrals vSurface … vInk; the dark twin adds D (vtealD). Do not mix families with !; the result is off-palette.

vellum axis style: bottom axis line, horizontal hairline grid, no tick marks, muted tick labels with a true minus, slot order at 1.6 pt, frameless legend. The axis title is the unit line; the claim goes outside the axis in the serif. vellum 3d: view, box, flat shading, horizontal axis names (z buffer=sort on the surface plot only). Dark variants: vellum dark, vellum 3d dark. Colormaps: vellum lagoon, vellum ember, vellum shore and the single families, each with dark. TikZ: vellum box, vellum box tint=<family>, vellum arrow, vellum guide, vellum label, vellum claim; \vellumtikzdark switches to the dark twin.

\node[vellum box tint=indigo] (a) {source\\ the data};
\node[vellum box tint=teal, right=1cm of a] (b) {script\\ draws the figure};
\draw[vellum arrow] (a) -- node[vellum label, above] {reads} (b);

Beamer: \vellumbeamer or \vellumbeamerdark sets structure in teal, alerts in terracotta, blocks on the card, serif frame titles, no navigation symbols. Used for the talk deck and the A0 poster.

Web

vellum.css: every colour as a --v-* variable under :root, dark values under [data-theme="dark"], plus fonts and the three gradients. This site uses it.

vellum-web.js reads vellum.json and provides SVG helpers: axes with grid and unit line, ringed dots, dotted reference lines, endLabels with leaders, a value-first tooltip, and colour science (OKLCH, colour-vision simulation, ΔE, contrast) matching the Python generators. Plain JavaScript, no dependencies; used for the interactive page.

Charts read the tokens at run time, so they follow the page theme.

import * as V from "./vellum-web.js";

const node = document.querySelector("#co2");
const plot = V.frame(node, { title: "Carbon dioxide rose every year since 1959",
                             subtitle: "Mauna Loa, annual mean", footer: "NOAA GML · co2.js" });
V.responsive(plot, (width, P) => {       // redraws on resize and when the twin flips
  V.clear(plot);
  const s = V.svg(plot, width, 320), g = V.el("g", { transform: "translate(44,28)" }, s);
  const x = V.linear([1959, 2019], [0, width - 140]), y = V.linear([300, 420], [248, 0]);
  V.axes(g, P, { x, y, xticks: [1960, 1990, 2019], yticks: [300, 350, 400],
                 xfmt: V.year, unit: "parts per million", width: width - 140, height: 248 });
  V.line(g, rows.map((r) => [x(r.year), y(r.ppm)]), P.tone[0]);
  V.reference(g, P, { y: y(350), x1: 0, x2: width - 140, label: "350 ppm" });
});

Office, Canva, Excalidraw, Google

PowerPoint and Word

  1. Design → Variants → Colors → Customize. Dark 1 ink 2A2825, Light 1 surface FFFFFF, Dark 2 secondary 5A5650, Light 2 card FAF6EE.
  2. Accents 1–6, tones in slot order: 419BA0 A1644F 415688 806629 AD78A1 567E4D. Hyperlink: 415688.
  3. Fonts: Palatino Linotype headings, Corbel body. Save as Vellum.thmx; make a dark theme from the TSV's dark rows.
  4. Charts: gridlines E6E0D4 at 0.5 pt, no border, no vertical gridlines, no legend up to four series, text boxes at line ends, chart area no fill.

Canva

  1. Brand Kit → Colors: seven neutrals, six tones and six tints from vellum-office.tsv, named by family and step; status colours in a group "status, with an icon".
  2. Fonts: Palatino Linotype headings if uploads are allowed, else EB Garamond; Lato body.
  3. One template per infographic format: headline, three tiles, figure slot, white surface.
  4. Import figures as PNGs at the format's pixel size; Canva charts cannot do end labels or rings.

Excalidraw

White background. Boxes: 1 px secondary #5A5650 stroke, card or tint fill. Text: ink, 16 px, "normal" font. Arrows secondary, guides dotted rule #C7C3BD, labels muted. Highlights: terracotta tint with terracotta deep text. Roughness 0.

Google Docs and Slides, Excel

Enter colours from the TSV in the custom picker. Lato body; EB Garamond or Libre Baskerville headings (Google has no Palatino). Excel tables: ink header on card, alternate rows in card, lining figures. Report charts: draw with vellum.py or vellum.R from exported CSV.

Not used: gradient fills on shapes, slides or text (only legend bars, from the TSV's nine stops); Office or Canva 3D charts. Put 3D figures in decks as PNGs from matplotlib or R at slot size.
