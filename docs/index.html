The signature

Seven things that are always true

These seven marks identify a Vellum figure. They hold in every medium, from a journal column to an A0 poster to a phone screen, and in both twins: the white page and the warm charcoal one used for talks.

  1. 1A white page, cream cards

    The surface is white (warm charcoal #2A2520 in the dark twin) and every grey on it is warm. Panels, tiles and boxes are cream. A figure never sits on cream, so a journal never needs a second version.

  2. 2The title is a claim

    A sentence with a verb, set in Palatino, left aligned, in ink. "Carbon dioxide rose every year since 1959", not "CO₂ over time". The rest of the text is a humanist sans.

  3. 3Six families, one fixed order

    Series take the tones in the order teal, terracotta, indigo, ochre, mauve, moss, and never reorder to taste. Areas take the matching tints; emphasis and text on a tint take the deep step.

  4. 4Direct labels, no legend box

    A line ends in a dot ringed in the surface colour and a label in ink. Four series or fewer get no legend; five or six get a legend and keep their end labels; seven or more are folded or faceted.

  5. 5A hairline grid, no frame

    Horizontal gridlines only, hairline, one step off the surface. No top, right or left spine, no box, no vertical grid, never a dashed grid. The data are the loudest thing on the page.

  6. 6A unit line, never a rotated label

    The quantity and its unit sit as a short line above the y axis, in muted text, read the right way up. The x label stays under its axis.

  7. 7A footer that traces the figure

    Bottom left, small, muted: the data, the script that drew it and the git commit, with -dirty when the tree was not clean. A figure that cannot be traced is not finished.

The numbers

Muted, and still distinguishable

Six soft colours at one lightness look like six greys. Vellum keeps the chroma low on purpose and makes neighbouring series differ in lightness as well as hue, so the tones stay apart for full-colour readers, for readers with red–green colour-vision deficiency, and in greyscale print.

18.3smallest colour distance between neighbouring series (ΔE, OKLab × 100)floor 15
11.4the same distance under protanopia or deuteranopiatarget 8
3.27:1lowest contrast of a line colour on the white pagefloor 3:1 for marks
1file defines every colour; every other file is generated from itstyle/vellum.json

If a figure needs a colour that is not in vellum.json, the figure is wrong, not the file.

Vellum, start here

A gradient is a data scale or it is absent. A gradient that can be removed without losing information is decoration.

Vellum, colour gradients

Written after studying Visual Cinnamon, the R Graph Gallery, Color Hunt and Canva's colour vocabulary, with colour science from OKLab (Ottosson 2020) and Machado, Oliveira and Fernandes (2009). What was taken from each.

The files

One file defines every colour; every tool reads it or is generated from it

vellum.json holds both twins: the neutrals, six families of three steps, seven-step ramps, the diverging scale, three gradients, the status set, the fonts and the sizes. The matplotlib and web modules read it at run time; the R theme, the LaTeX package, the CSS and the Office list are generated from it, byte for byte.

Quick start

Load the style in the tool you already use

import sys; sys.path.insert(0, "vellum/style")
import vellum
import matplotlib.pyplot as plt

V = vellum.use("light")                    # "dark" for the twin; scale=2.2 for slides, 2.6 for posters
fig, ax = plt.subplots(figsize=V.size("double"))
fig.subplots_adjust(left=0.07, right=0.84, top=0.74, bottom=0.17)
ax.plot(year, ppm, color=V.tone(0))        # tones for lines, tints for areas
V.dot(ax, year[-1], ppm[-1], V.tone(0))    # ringed end dot
V.endlabel(ax, year[-1], ppm[-1], "annual mean")
V.reference(ax, y=350, text="350 ppm")     # dotted ochre, label at the right end
V.panel(ax, unit="parts per million")      # the unit line, no rotated y label
V.title(fig, "Carbon dioxide rose every year since 1959", "Mauna Loa, annual mean",
        "NOAA GML · co2.py · git " + vellum.stamp())
fig.savefig("co2.pdf"); fig.savefig("co2.png")
source("vellum/style/vellum.R")
library(ggplot2)
vellum_fonts()                              # registers Palatino and Corbel for the png device

ggplot(d, aes(year, ppm, colour = series)) +
  geom_line(linewidth = vellum$lw) +
  geom_point_vellum(data = ends, size = 2) +            # ringed points
  label_ends_vellum(ends, year, ppm, series, nudge = 1) + # direct labels
  scale_colour_vellum() +                               # tones in slot order
  labs(title = "Carbon dioxide rose every year since 1959",
       subtitle = "Mauna Loa · parts per million", caption = "NOAA GML · co2.R",
       x = NULL, y = NULL) +
  theme_vellum()                            # theme_vellum(V = vellum_dark) for the twin
\usepackage{tikz}
\usepackage{pgfplots}\pgfplotsset{compat=1.18}
\usepackage{vellum-colors}                  % after tikz and pgfplots: names, axis styles, TikZ node styles, beamer

\begin{tikzpicture}
  \begin{axis}[vellum, width=8.4cm, height=5cm, xlabel={year}, title={parts per million}]
    \addplot table {co2.dat};                      % the cycle list: teal, 1.6 pt
    \addplot[vochre, line width=0.6pt, dash pattern=on 1pt off 2pt] coordinates {(1958,350) (2020,350)};
  \end{axis}
\end{tikzpicture}
